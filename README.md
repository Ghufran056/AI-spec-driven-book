# 📘 AI-Driven Textbook – Physical AI & Humanoid Robotics

An interactive AI-native textbook built with **Docusaurus** for the Hackathon: *Create a Textbook for Teaching Physical AI & Humanoid Robotics*.

The project provides a modern documentation website along with an embedded AI chatbot capable of answering questions about the book using Retrieval-Augmented Generation (RAG).

## 🤖 AI Chatbot

The chatbot communicates with a separately deployed FastAPI backend.

Workflow:

User
↓
Docusaurus Chat Widget
↓
FastAPI Backend
↓
OpenAI Agents SDK
↓
Qdrant Vector Database
↓
Cohere Embeddings
↓
Relevant textbook chunks
↓
Answer returned to the user
